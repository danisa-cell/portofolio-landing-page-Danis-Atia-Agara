# 🌐 3D Interactive Personal Portfolio — Danis Atia Agara

Selamat datang di repositori portofolio digital interaktif saya! Website ini dirancang untuk menampilkan profil profesional, keahlian teknis, pengalaman magang enterprise, dan kumpulan proyek rekayasa perangkat lunak yang telah saya kembangkan.

![Portfolio Preview](img/portfolio-1.jpg)

---

## ✨ Fitur Utama (Key Features)

- 🎨 **Visual Interaktif 3D**: Diintegrasikan dengan Three.js untuk tampilan antarmuka modern dan dinamis.
- 💼 **Showcase Proyek Enterprise & Kampus**:
  - **IMS Food Ordering System** *(PT INKA Multi Solusi)* — Sistem manajemen pemesanan makanan vendor real-time.
  - **IMS Single Sign-On (SSO Portal)** *(PT INKA Multi Solusi)* — Portal otentikasi terpusat & manajemen hak akses akun.
  - **IMS Dashboard Executive** *(PT INKA Multi Solusi)* — Visualisasi analitik data & laporan statistik eksekutif.
  - **CRM System Jawaratech** — Aplikasi manajemen hubungan pelanggan berbasis Laravel & MySQL.
- 🏅 **Kualifikasi & Sertifikasi BNSP**: Pengembang Web Pratama (*Junior Web Developer*) resmi BNSP (2025) & Praktik Kerja Industri PT INKA Multi Solusi (2026).
- 📲 **Click-to-Chat WhatsApp Integration**: Formulir kontak interaktif langsung ke WhatsApp untuk kemudahan kolaborasi bisnis.
- 📱 **Responsif & Smooth Animation**: Dioptimalkan secara penuh untuk perangkat *desktop* maupun *mobile*.

---

## 🛠️ Tech Stack & Alat Pengembangan

- **Frontend**: HTML5, CSS3, JavaScript (ES6+), Three.js, Bootstrap
- **Backend & Database**: PHP, Laravel, MySQL / MariaDB
- **Infrastruktur & Tools**: Git, GitHub, Linux, VS Code, Figma, Canva
